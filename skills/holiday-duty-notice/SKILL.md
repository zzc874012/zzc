## 一、适用范围

用于起草公司各部门、各所属单位在节假日放假期间的值班安排类通知，例如：
财务部、办公室、行政部、信息中心等部门的中秋国庆、春节、元旦等假期值班安排通知。

## 二、硬性规范（必须遵守）

1. **标题必须包含部门名称**，格式为：
   `【部门名称】关于【年份】年【节日】假期值班安排的通知`
   例如"财务部关于2025年中秋国庆假期值班安排的通知"，
   **不能**只写"关于中秋国庆假期值班安排的通知"。

2. **落款处必须写明起草人姓名**，位于部门名称的正下方：

   > 财务部
   > 张三
   > 2025年9月20日

3. **起草人姓名未知时必须先询问用户**，获得确切姓名后方可起草，不得留空或使用占位符【姓名】代替。

4. **成文日期不得出现【XX】等未填写占位符**，须写明具体日期。

## 三、标准结构

通知正文按以下顺序组织：

| 部分 | 内容要点 |
| :--- | :--- |
| **开头** | 说明发文背景与目的（保障节日期间业务运转、资金支付、系统运行、应急处置等），以"现将……有关事项通知如下。"收尾 |
| **一、假期时间** | 放假起止日期、总天数；调休上班的日期 |
| **二、值班安排** | 每日值班时段、值班地点，以及含"日期 / 星期 / 值班人员 / 联系电话"的表格；末尾注明值班负责人及电话 |
| **三、值班职责** | 分条列出，建议包含：按时到岗、保障业务连续性、安全巡查、信息报告、规范值班记录 |
| **四、其他事项** | 通讯畅通、加班费或调休、值班日志归档时限、离岗前安全检查 |
| **结尾** | "请相关人员遵照执行。""特此通知。" |
| **落款** | 部门名称 → 起草人姓名 → 成文日期 |

## 四、起草流程

1. **核实日历**：用 `python -c "import datetime..."` 等方式确认假期各日期对应的星期，确保表格中"日期+星期"与实际日历一致，避免如"10月1日（周三）"之类的错误。
2. **确认关键信息**，若用户未提供则逐项询问：
   - 起草部门名称、起草人姓名
   - 假期起止日期与调休安排
   - 每日值班时段、值班地点（楼层/房间号）
   - 值班人员姓名与联系电话（逐日）
   - 值班负责人姓名与电话
   - 成文日期
3. **套用模板生成正文**，按第三部分结构撰写。
4. **成稿后自查并列出待补清单**：检查是否存在【楼层/房间号】【姓名】【联系电话】【XX】等未替换占位符，如有，逐一列出提醒用户补全。

## 五、语言风格

- 采用正式公文语体："为切实做好……""现将……通知如下""须""不得""应"。
- 职责条款用"（一）（二）（三）"编号，条目小标题加粗。
- 值班表格中节日当天需标注节日名，如"10月6日（中秋节）"。
- 涉及金额、频次、时限的要求尽量量化（如"提前10分钟到岗""24小时联络畅通""10月9日交部门汇总归档"）。
